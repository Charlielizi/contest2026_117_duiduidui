# 板端 UI 模拟器图集

Task: TASK-20261004-01；Primary Module: Device UI。以下六张画面以当前公开版的 **C/LVGL 板端 UI 原码**、项目既有 `lab_ui_demo` 数据，在 Windows LVGL/SDL 桌面模拟器中重新渲染。不是网页重绘、AI 生成图、实体屏幕照片，也不是运行 R528 固件的 Goldfish 截图。

原生分辨率 **320×240**，PNG 直接保存软件渲染结果，未裁剪、缩放或修改像素。所有任务、传感器、联网/麦克风标志、语音文字和告警均为 **Mock 演示数据**；时钟来自电脑，不能证明板端校时。此图集只说明页面结构和状态呈现，不新增硬件、云服务、持久化或触控验收结论。

## 1. 实验台主页

![同源模拟器：主页与环境摘要](images/sim-ui-idle.png)

主页将时钟、天气、温湿度、距离和最近实验收纳在一屏，底部提供开始实验、语音和多任务入口。截图中的 24.5℃、60%、天气和最近记录来自固定演示数据，不是真实测量或历史实验。

## 2. 运行中的实验

![同源模拟器：实验步骤与倒计时](images/sim-ui-running.png)

突出当前实验、剩余时间、步骤/进度与环境摘要；暂停、下一步、结束按钮分列底部。`A-203`、步骤 4/8 和 04:51 均为既有 demo 场景，仅展示状态，不执行酸碱滴定或其他化学操作。

## 3. 并行计时与焦点切换

![同源模拟器：并行任务与计时焦点](images/sim-ui-timers.png)

焦点任务使用大号倒计时，其他任务保留紧凑状态，底部提供返回、切换焦点和结束。列表中的运行/暂停与计时值是模拟状态；本次没有等待真实计时到期或触摸操作。

## 4. 语音前台与文字显示

![同源模拟器：语音状态与识别文字区域](images/sim-ui-voice.png)

状态、置信度/元信息与实时标记位于顶部，正文置于独立阅读卡片，底部有取消/确认。文字和 92% 置信度由 demo 直接注入，**没有麦克风采集、ASR、唤醒、模型回复或 TTS 调用**；不能当作真实识别效果。

## 5. 环境告警

![同源模拟器：温度告警与确认入口](images/sim-ui-alert.png)

告警页展示规则、关联实验、当前值和阈值。31.2℃、28.0℃、告警编号及“事件写入时间线”均是既有 fixture 文案，截图本身不证明真实传感器触发或事件落盘。

## 6. 完成实验确认

![同源模拟器：完成实验前的确认](images/sim-ui-complete-confirm.png)

展示最后一步完成时的确认与返回入口，说明结束动作不与普通“下一步”混为一体。这是**板端 UI 的模拟流程确认**，不是网页 Agent 120 秒令牌弹窗，也没有执行真实完成请求。

## 来源与复现

- UI 来源：`vendor/allwinnertech` revision `678904361b8f1b29d43bdf675270fddfe13273c7`，与公开快照一致。渲染时核对四个 C 文件和五个头文件与 Ubuntu 权威源的 SHA 相同；未修改 UI、demo 或 token。
- 使用 LVGL 9.1.0、SDL 2.32.10、既有 w64devkit GCC 16.1.0；SDL `dummy`/software 离屏渲染，不控制桌面窗口、鼠标或键盘，不运行板端网络/音频服务。
- 字体：同一 MiSans-Normal.ttf（SHA-256 `fe0adb56147299e53d5b208a561d6ca7fe4ce5c727a5ead38ad9827b26024f3a`），沿用桌面预览的七档 TinyTTF 字号和 CJK fallback。桌面字体栅格化不等同于目标板所有字体/显示配置；字体、依赖库和 exe 不上传。
- [模拟图像来源清单](images/simulator-manifest.json)记录六图的尺寸、大小、SHA 和渲染输入；[实板网页图集](SCREENSHOTS.md)保持独立，两类证据不混称。

维护者已有项目 `ui_preview` 的 LVGL/SDL/w64devkit/字体依赖和 `liblvgl-preview.a` 后，可在公开仓 PowerShell 中运行：

```powershell
.\labtwin\tools\Capture-UiScreenshots.ps1 -PreviewRoot <已准备的ui_preview目录>
```

脚本编译 [capture_ui.c](../tools/capture_ui.c)，链接已有软件渲染库，调用原 UI 和 demo 场景并一次性保存六图，不下载/安装软件，不改板端服务或源码；构建目录保留供核查。主页时间随电脑时间变化，因此重新截图的字节 SHA 不保证与本图集相同。未准备预览依赖时会直接报错，不声称公开源码可零依赖启动模拟器。
