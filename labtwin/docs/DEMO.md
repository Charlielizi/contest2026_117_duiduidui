# 现场演示指南（约 5～8 分钟）

Task: TASK-20261003-06。此页是供人执行的演示流程，**编写文档和补拍截图时没有执行以下新建/录音/云操作**。使用无危险的本地观察测试，不连接真实仪器。

## 演示前

- 连接板卡所在受控局域网，使用设备实际 IP 打开网页；截图中的地址不是通用固定地址。
- 公开版需要设置/登录管理员并自行配网，不能套用截图中私人免密默认。不要向观众展示 API Key、密码或私人聊天。
- 确认在线、传感器和存储状态；涉及云服务先确认板端时间可信、TLS 就绪、有效凭据与额度。
- 留有录音空间并确认板卡麦克风可用；本地能力演示不要求云端配置。一小时录音不是这个短演示的验收内容。
- 重启演示必须事先征得设备使用者同意并退出 PhoenixSuit/PhoenixDaemon；不要把刷机擦除当作普通重启测试。

## 1. 从任务到过程（约 2 分钟）

在“实验任务”创建“演示：样品观察”，说明写“惰性测试，不进行真实化学操作”，设置计划时间和两个步骤：“准备与核对样品”“记录观察结果”。READY 状态展示编辑和步骤调整，然后启动。

追加一条观察，例如“外观无明显变化”；设置 60 秒倒计时，展示计时状态与到期提示。按当前界面演示暂停/恢复。启动后名称/步骤等结构不应再任意编辑，拒绝和冲突需明确提示。

讲解点：任务不是聊天文本，状态、计时、观察和事件序号都在板端。这里不承诺板卡替你执行物理实验。

## 2. Agent 与受控动作（约 1 分钟）

先用 `/time` 演示网页与板端 Agent 的本地链路，然后刷新页面查看恢复的记录。该命令由本地处理，不是模型推理。

只有现场配置有效且允许云调用时，再让 Agent 查询演示任务；可请求为该任务计时或追加观察。请求完成/取消/删除时展示待确认摘要、时限和取消按钮。用户确认前不应执行；删除只能使用演示任务的完整编号，公开密码模式还需管理员密码。没有有效模型配置时直接展示源码/测试说明，不伪造模型回复或确认弹窗。

讲解点：对话共享能力而不共享上下文；高影响操作的安全边界由可信程序层约束。

## 3. 日历与回查（约 1 分钟）

切到“任务日历”，依次展示月/周/列表、状态或关键词筛选，点击任务查看详情和时间线。对照计划与实际开始时间，解释 READY 用排期，历史用实际发生时间。完成演示任务后重新查看历史列表；不要为截图修改设备时钟。

讲解点：同一条任务既有事前计划，也有事后记录，不是另造一份日历假数据。

## 4. 现场证据（约 1～2 分钟）

“环境监控”展示已有真实温湿度趋势、规则及告警。时间未知的旧事件应保持不可信标记。无需为了演示触发极端环境或随意改变正式阈值。

打开右下“录音”，征得现场说话者同意后录 15～30 秒，前后留几秒安静，停止并回放；拖动进度、查看历史条数和最新优先顺序，再刷新核对。音频只留板端，不上传仓库或云服务。录音是板载麦克风采集，不应申请电脑麦克风权限。

讲解点：原生 WAV/Range、配额、单采集所有者以及正常停止发布。短演示不能证明一小时耐久、专业音质或长期唤醒性能。

## 收尾与诚实说明

保留演示任务或录音需获得所有者同意；删除需要明确确认，勿一键清空真实历史。若另外安排普通断电恢复测试，应先停止录音和活动任务、保存必要信息，并比较重启前后的 ID、状态及文件哈希。

当前公开包与私人参考截图的认证、网络和模型默认不同。真实云 Agent/ASR/TTS、板载声音输出、离线唤醒泛化、一小时录音和公开版完整实板验收未全部闭环。展示 [实板图集](SCREENSHOTS.md) 和 [验证记录](VALIDATION.md)，把“已实现”“主机通过”“私人实板通过”“待验收”分开。
